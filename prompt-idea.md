Tool-lab is our proposed method for analyzing llm behavior. It adapt the classic human process tracing method from cognitive psychology, that is mouselab mdp, to test llms in practical contexts to see whether the llms reasoning and information acquisition is optimal from a meta planning perspective. We want to write a paper introducing the method.

Tool-Lab presents pieces of information behind tool calls for LLMs. The LLM has to decide which piece of information to acquire, when to stop, and what final decision to make.

For the normative optimum, we need to structure environments with known optimal metalevel MDP policies.

We need to see which experiments we should run so that the paper gets published in a high ranking CS journal/conference.
